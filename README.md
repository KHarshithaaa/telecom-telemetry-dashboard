\# Telecom Telemetry \& Analytics Dashboard



A production-grade, real-time network telemetry monitoring and automated alerting API built with \*\*FastAPI\*\*, \*\*Pydantic\*\*, \*\*Docker\*\*, and \*\*Pytest\*\*.



\## 🚀 Features

\- \*\*Real-time Telemetry Ingestion\*\*: Securely tracks network metrics like device ID, latency, packet loss, and signal strength.

\- \*\*Automated Alerting Engine\*\*: Evaluates thresholds dynamically to flag high latency (>100ms) or packet loss (>5%).

\- \*\*API Documentation\*\*: Auto-generated interactive Swagger UI (`/docs`).

\- \*\*Containerization\*\*: Fully optimized Docker setup for cloud deployment.

\- \*\*Automated Testing\*\*: Robust unit test coverage using Pytest.



\## 🛠️ Tech Stack

\- \*\*Backend\*\*: Python, FastAPI, Pydantic, Uvicorn

\- \*\*Testing\*\*: Pytest, TestClient

\- \*\*DevOps \& Tools\*\*: Docker, Git, GitHub
